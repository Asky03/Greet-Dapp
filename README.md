# 👋 Greeter DApp

A simple decentralized application (DApp) built using Solidity, Hardhat, Ethers.js, and Vanilla JS to store and update a greeting message on the Ethereum blockchain.

---

## 🚀 Live Demo

🔗 [Frontend on Vercel](https://greeter-dapp-ashu.vercel.app)

> ⚠️ Make sure your MetaMask is connected to **localhost:8545** and unlocked with a Hardhat test account.
> ⚠️ You can create a new Hardhat test account using `npx hardhat
account` command.


---

## 🛠 Tech Stack

- **Solidity** – Smart contract language
- **Hardhat** – Development environment and local blockchain
- **Ethers.js v5** – Web3 library for frontend interactions
- **HTML + Vanilla JS** – Lightweight frontend
- **MetaMask** – Ethereum wallet for signing transactions
- **Vercel** – Frontend hosting
